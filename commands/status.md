---
description: Ревізія — що зроблено, що підтверджено, що далі
---

Покажи стан Ревізії в цьому проєкті.

Прочитай теку `docs/revision/`. Немає — ревізія не починалася, запропонуй `/restrukt:run`.

Читай лише шапки файлів: перший рядок чисел і секцію «Хід перебудови». Виведи таблицю:

| Що | Звідки |
|---|---|
| Сценарії | `_map.md`: скільки, який обрано, скільки маршрутів пройдено |
| Маршрути | шапка кожного: факти, безіменні, тест повноти |
| Судження | шапка `.judgement.md`: по шарах, підтверджено, виконано |
| Перебудова | «Хід перебудови»: які шари виконані |
| Друга думка | секція: запитувалась чи ні, розбіжностей |
| Звірка | `.verify.md`: порушень, дрейфу, приросту |
| Відкрите | відкриті межі, вироки «потрібен ще маршрут», сусідні маршрути |

Артефакту немає — `—`, не пропускай. Заверши одним рядком: яку команду далі і для чого.
