---
description: Ревізія — що зроблено, що відкрито, що далі
---

Покажи стан Ревізії в цьому проєкті.

Прочитай теку `docs/revision/`. Якщо її немає — скажи, що ревізія не починалася, і запропонуй `/restrukt:run`.

Виведи таблицю, без прози:

| Що | Звідки брати |
|---|---|
| Сценарії | `_map.md`: скільки всього, які в робочому наборі |
| Маршрути | по файлу: реєстри заповнені, тест повноти пройдено |
| Діагноз | чи є `.diagnosis.md`, скільки знахідок по шести шарах |
| Модулі | таблиця шару 5: скільки з трьома «і» й більше |
| Модель | чи є `.model.md`, чи підтверджені імена і вироки, скільки модулів на ремонт і на перебудову |
| Перебудова | `.model.md`, таблиця «Хід перебудови»: які шари зроблені, які пропущені |
| Сусідні маршрути | `_map.md`: скільки запропоновано, яка користь у найкориснішого |
| Друга думка | `.diagnosis.md` і `.model.md`: скільки розбіжностей лишилося без відповіді |
| Звірка | чи є `.verify.md`, скільки порушень контракту, дрейфу, приросту |
| Відкрите | відкриті межі з шапок маршрутів; маршрути без тесту повноти; вироки «потрібен ще маршрут» |
| Словник | скільки термінів, скільки з двома значеннями |

Рядок, для якого артефакту ще немає, пиши як `—`, не пропускай.

Заверши одним рядком: яку команду запускати далі і для чого.
