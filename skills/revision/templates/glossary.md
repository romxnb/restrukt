# Словник проєкту

<!-- Етап 4 дописує сюди свої імена. Тому цей файл не показують консультантові: для нього це модель, а не інвентар. -->

Терміни **цього коду**, людською мовою. Одне речення на термін.

Терміни методу — сценарій, фрагмент, риба, ребро, термінатор — сюди не йдуть: вони живуть у скілі.

Файл накопичується між прогонами. На етапі 4 безіменні факти отримують тут свої назви, і цей файл стає ubiquitous language проєкту.

Колонка «сходинка» — рівень імені за драбиною Белші, від 0 до 6. Її заповнює етап 3, бо сходинка є судженням. Етап 1 лишає її порожньою.

Вона показує, куди рухається мова проєкту від прогону до прогону.

| термін | що це | значень | сходинка | де вжито |
|---|---|---|---|---|
|  |  | одне | n |  |
|  |  | ⚠️ **два** — ... і ... | n |  |
