# Словник проєкту

<!-- Судження дописує сюди свої імена. Тому цей файл не показують консультантові: для нього це пропозиція, а не інвентар. -->

Терміни **цього коду**, людською мовою. Одне речення на термін.

Терміни методу — сценарій, фрагмент, риба, ребро, термінатор — сюди не йдуть: вони живуть у скілі.

Файл накопичується між прогонами. У судженні безіменні факти отримують тут свої назви, і цей файл стає ubiquitous language проєкту.

Колонка «сходинка» — рівень імені за драбиною Белші, від 0 до 6. Її заповнює судження. Огляд лишає її порожньою.

Вона показує, куди рухається мова проєкту від прогону до прогону.

Колонка «у документах» — де термін уже записаний у джерелах мови з `_map.md`, або `—`. Інше слово там на ту саму річ — розходження, воно живе в судженні.

|  |  | одне | n |  | `CLAUDE.md:14` |
|  |  | ⚠️ **два** — ... і ... | n |  | — |
