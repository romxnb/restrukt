# Показати стан

Прочитай обраний план і потрібні останні записи журналу; файли не змінюй. Без однозначного вибору покажи всі плани одним рядком кожен: назва, обсяг, наступна дія. Покажи обсяг, готові задачі, незавершену задачу, перешкоди, стан перевірки цілого й наступну дію. Наступний крок визначай за залежностями та точкою продовження.

Плану немає — запропонуй `plan`. Старий формат або план без теки — назви потребу перенесення без правок. Усі задачі готові, ціле не перевірене — наступний крок `review`; знахідки вже мають задачу — `apply` цієї задачі. Не видавай збережений стан за нову перевірку коду.
