# Назви: окремий прохід

Вхід: обсяг коду. Вихід: назви обсягу за [методикою назв](../methods/naming.md), оновлені використання й перевірена поведінка.

1. Прочитай код обсягу разом із місцями використання назв. Розглядай усі рівні: папки, модулі й файли, типи, функції, змінні й параметри. Місця використання модуля — його імпорти й виклики через його назву.
2. Знайди назви, які методика велить перейменувати: оманливі, неузгоджені з іншими назвами того самого поняття або незрозумілі в місці використання. Для кожної запиши одним реченням, що саме читач зрозуміє хибно чи не зрозуміє.
3. Для кожної обери назву кроками «Як назвати».
4. Проста назва не знаходиться — поверни це як знахідку дизайну, а не як довшу назву.
5. Перейменуй усі використання засобом мови, з урахуванням конфігурації, серіалізації й зовнішніх споживачів.
6. Запусти збірку чи перевірку типів і зачеплені поведінкові перевірки.
7. Покажи кожне перейменування `було → стало` з причиною.

Приймання — за методикою назв; поведінка збережена.
